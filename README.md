# Drill #9: 소년 이동과 방향 전환

`Drill_09_2023180036.py`가 과제 실행 파일이다. Python과 pico2d가 설치된 환경에서 실행한다.

## 실행

다음 세 파일을 같은 폴더에 둔다.

- `Drill_09_2023180036.py`
- `animation_sheet.png`
- `TUK_GROUND.png`

```powershell
python Drill_09_2023180036.py
```

다른 작업 폴더에서 실행할 때는 Python 명령에 실행 파일의 전체 경로를 지정한다. 이미지 경로는 실행 파일 위치에서 자동으로 계산한다.

## 조작

| 키 | 동작 |
| --- | --- |
| ← / → | 좌우 이동 및 바라보는 방향 변경 |
| ↑ / ↓ | 마지막 좌우 방향을 유지하며 상하 이동 |
| ESC | 종료 |

방향키 입력과 화면은 초당 60회 갱신을 목표로 한다. 매번 현재 키 상태를 읽으며, 키를 놓거나 창이 키보드 포커스를 잃으면 이동을 멈춘다. 이동 속도와 애니메이션 속도는 경과 시간 기준으로 유지한다.

창 닫기로도 종료할 수 있다. 반대 방향 입력은 상쇄되며, 가로·세로 방향키를 함께 누르면 대각선으로 이동한다.

화면은 1200 × 800이다. 정지 시 IDLE 애니메이션을 재생하며, 캐릭터 전체가 화면 밖으로 나가지 않도록 이동을 제한한다.

## 검증

```powershell
python test_drill_09.py
python test_drill_09_render.py --portable
```

첫 번째 명령은 입력·방향·애니메이션·화면 경계 로직을 확인한다. 두 번째 명령은 현재 키 상태를 모의하고 실제 SDL 이벤트 큐와 화면을 띄우지 않는 소프트웨어 렌더링을 검사하며, 프로젝트를 한글·공백 경로로 옮겨 별도 작업 폴더에서 실행하는 검사도 수행한다.

렌더링 결과를 저장하려면 다음 명령을 사용한다. 캡처 폴더는 저장소 밖의 임시 경로를 지정한다.

```powershell
python test_drill_09_render.py --capture "$env:TEMP\Drill09-captures"
```

별도 컴퓨터에서의 실행과 실제 키보드를 직접 눌러 조작하는 검사는 자동 검증에 포함되지 않는다.
